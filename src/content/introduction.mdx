## What it is

Fusion Kit started as an internal pattern I kept rebuilding across different
projects: the same class-name merge helper, the same RTK Query auth-refresh
wrapper, the same form-to-API glue. Instead of copy-pasting it between
codebases, I pulled it into one published package so it's versioned,
tested, and reusable.

It's built for **Next.js 13+** apps (App Router or Pages Router) written in
TypeScript, and it's meant to be imported piece by piece rather than as one
large bundle.

## Why subpath imports

Fusion Kit ships each feature area as its own subpath — `fusion-kit/hooks`,
`fusion-kit/format`, `fusion-kit/query-utils`, `fusion-kit/ui`, `fusion-kit/forms`
— instead of one flat export. That means your bundler only pulls in the code
you actually import, and a project that only needs the `cn()` class-name
helper doesn't also ship RTK Query glue it never calls.

<Note type="info" title="Who this is for">
  Fusion Kit is for React/Next.js developers who are tired of re-solving the
  same small problems (debounced inputs, currency formatting, auth-refresh
  base queries) in every new project and want a tested, versioned place to
  pull them from instead.
</Note>
