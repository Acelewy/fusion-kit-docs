title: Quickstart
description: Install Fusion Kit and merge your first class names.
---

This quickstart gets you from an empty terminal to a working `cn()` call —
Fusion Kit's class-name merge utility — in a Next.js project.

## Prerequisites

- Node.js 18 or later
- An existing Next.js 13+ project (App Router or Pages Router)
- Tailwind CSS configured in that project

<Steps>
  <Step title="Install the package">
    <Tabs>
      <Tab title="npm">
        ```bash
        npm install @llvveess/fusion-kit
        ```
      </Tab>
      <Tab title="pnpm">
        ```bash
        pnpm install @llvveess/fusion-kit
        ```
      </Tab>
      <Tab title="yarn">
        ```bash
        yarn add @llvveess/fusion-kit
        ```
      </Tab>
    </Tabs>
  </Step>

  <Step title="Import cn from the root export">
    `cn()` merges Tailwind class strings and resolves conflicts — later
    classes win, so conditional styling doesn't fight your defaults.

    ```tsx
    import { cn } from "@llvveess/fusion-kit";

    function Button({ active, className }: { active?: boolean; className?: string }) {
      return (
        <button
          className={cn(
            "rounded-md px-4 py-2 text-sm font-medium",
            active ? "bg-black text-white" : "bg-gray-100 text-gray-900",
            className
          )}
        >
          Click me
        </button>
      );
    }
    ```
  </Step>

  <Step title="Verify it worked">
    Render the component with `active` set to both `true` and `false`. You
    should see the background and text color swap cleanly, with no leftover
    classes from the inactive state bleeding through, that's `cn()` resolving
    the conflict between `bg-black`/`bg-gray-100`.
  </Step>
</Steps>
